# Demo and submission

## Honest pitch

Pact — Changes agreed. Work aligned.

'When a customer changes an agreed job, Pact helps the business update the scope, get approval, collect the correct payment and give the team the current instructions.'

Prototype status must match the actual build. No customers, savings, reduced disputes or revenue claimed without measured evidence.

## 2:45 functioning video storyboard

- 0:00–0:20: Show original apparel job, approved proof and completed sandbox deposit. Explain owner/coordinator task.
- 0:20–0:50: New message substitutes hoodies and replaces artwork. AI produces a cited diff and flags missing sizes.
- 0:50–1:15: Merchant supplies sizes and approves pricing; customer sees changed terms and approves exact revision.
- 1:15–1:45: Customer approves real sandbox top-up; server verifies capture; current job sheet becomes ready after merchant release.
- 1:45–2:05: Replay request: no duplicate charge. Open stale approval link: it cannot approve the current revision.
- 2:05–2:25: Switch to website fixture. A question about booking stays a question; explicit extra deliverable becomes a reviewed amendment.
- 2:25–2:45: Show evaluated failure handling, implementation scope and factual limitations. End on current approved/funded job sheet.

All money is sandbox money. Fixture evidence is synthetic and labeled. Prerecord deterministic setup to fit time, but show actual functionality and do not disguise mock provider responses. A separate test transcript can substantiate failure cases outside the short video.

## Submission checklist

- [ ] Functional application matches the demonstration.
- [ ] PayPal sandbox calls and substantive AI behavior verified.
- [ ] Public source repository with detected open-source license.
- [ ] Complete install, migration, seed and run instructions OR accessible hosted build.
- [ ] Appropriate judge access instructions; no merchant secret/API keys in public source.
- [ ] AI model/tool and optional sponsor usage accurately disclosed.
- [ ] Public YouTube video strictly under 3 minutes.
- [ ] Screenshots, description, limitations and significant event-period work documented.
- [ ] Rights cleared for code, artwork, fonts and video assets.
- [ ] Eligibility and registration checked by entrant; no registration/submission performed by this documentation change.
- [ ] Testing access maintained through the judging period ending December 15, 2026.

## Rules and discrepancies

Official rules and overview agree on November 12 noon PST, equivalent to November 13 01:30 IST. No prescribed tracks. Sponsor tools optional; use only those with actual utility.

Overview headline shows $67,500 cash while promotional copy says $69,750 total prizes. Do not collapse this discrepancy into one guaranteed pool. No prize forecast is used in the business case.

The rules describe access details including test credentials/API keys; keep production secrets private and use hosted test access or secure sandbox setup instructions. Re-check official rules before submission.
