# Security

Pact is currently a blueprint; no production security guarantees are claimed. Do not use a future prototype with live payments or private customer records until the controls and access terms are verified.

Do not publish secrets, private customer data or exploitable details in public issues. Use GitHub private vulnerability reporting if enabled; otherwise contact the repository maintainer privately through a verified channel. No security contact address or reporting feature is assumed configured.

Threat model and required controls: [Security and legal boundaries](docs/pact/07-security-legal.md). Payment-specific recovery: [Payments](docs/pact/05-payments.md).
